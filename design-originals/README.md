# Original artwork

Full-size originals of images that are served in a smaller size.

- `categories-filter/` — the home category filter images at 480 px. The site
  serves 240 px copies from `public/categories/filter/` (they are shown at
  54–125 px, so 480 px only cost download time).

To go back to the originals: copy `categories-filter/*.webp` over
`public/categories/filter/`.
